## Possible gaps to check (only fix if confirmed)

1. `validateNewBook` has no test for the year boundaries (1449, 1450, current year, current year + 1, non-integer like `1999.5`, empty string). `Number("")` is `0`, so an empty year is rejected, but this is untested.
2. No test that the statistics change after adding a book (App-level test with `StatsCard`).
3. No test that an added book survives a reload (App rendered twice with the same storage).
4. `loadBooks` only checks `Array.isArray`; stored garbage inside the array is not validated. Out of scope for the issue unless a test shows a crash.
